## 攻略正文与一句话规划（2026-09-30）

以下为保留的真实生成能力，目前演示模式下关闭该入口。恢复真实模式后，在首页选择「粘贴攻略」或「一句话规划」，输入内容后点右侧箭头。示例按钮只填入文字，不会直接消耗生成调用。

- 攻略：支持小红书链接、包含链接的分享文案，或直接粘贴攻略正文。正文按原天数与先后顺序提取地点。
- 想法：例如「重庆玩 2 天，想吃美食、看夜景，节奏轻松一点」。支持国内单城市 1–7 天；未指定天数按 2 天并展示说明，缺城市提示补充。
- 自动安排后仍需核对地点，再点「确认并生成动线」。地图、住宿、导航与长图复用既有流程。地点调整下拉已支持 7 天。
- `POST /api/v1/trips` 兼容旧 `source_link` 字段，新增可选 `mode: guide | idea`（默认 guide）。输入最长 12000 字。`GET /trips/{id}/places` 新增输入模式、原文、概要与当前任务字段，供刷新恢复。

## 全站每天最多 10 元模型额度（2026-09-30）

- 所有用户共用一份 **DeepSeek 日预算 10 元**，北京时间每天 **00:00** 自动开始新额度，不累积前一天结余。
- 所有模型入口、失败重试均受后端限制。每次请求先原子预留费用上限，余额不足就返回提示；不会等调用结束后才判断是否超额。已有行程、地图与导出可继续使用。
- 采用保守费率核算（高峰价格、不计缓存折扣；旧别名使用已公布最高文本费率），实际账单可能更低。剩余额度不足覆盖一次完整请求时会提前拒绝。
- 超时、缺失用量或进程中断时保留整笔预留；确认没有发往模型的初始化失败才返还。账本保存于原 SQLite 的 `ai_budget_days` / `ai_usage`，重启不清空；不存原文与密钥。
- 查看本机状态：http://127.0.0.1:8000/api/v1/ai-budget 。`used_upper_bound_cny` 是已计入保守金额，`reserved_cny` 是在途占用，`remaining_cny` 是可用额度，`resets_at` 是北京时间恢复时间。无网络重置接口。
- 从本次启用后开始计量；本站以外的软件使用同一 Key 不受这里限制，百度地图和云服务器费用也不包含在 10 元内。多台服务器部署时必须共用账本，不能各用一份 SQLite。
- 不需要新增 Key 或配置。固定上限在 `backend/app/services/ai_budget.py`；已核对的费率快照在 `deepseek_pricing.json`，服务商调价或换模型时需要同步核对，不明费率拒绝调用。
- 验证：后端 `python -m pytest -q`（99/99）；真实小额调用已验证，封顶测试使用隔离账本。截图与步骤见 [预算证据包](开发文档/证据包/阶段3/2026-09-30-每日10元预算/验收说明.md)。

## 启动（单端口 8000）

```bash
# 1. 前端构建（首次 / 修改前端后）
cd frontend && npm install && npm run build

# 2. 后端启动（首次）
cd ../backend
python3.12 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/playwright install chromium        # 长图导出用

# 3. 启动服务
./.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

浏览器打开 http://127.0.0.1:8000/（完整文案已固定，点箭头打开预设演示）。
手机（同一 WiFi）打开 http://<电脑IP>:8000/。

## 密钥（`.env`）
- `BAIDU_MAP_AK`：百度地图开放平台「服务端」AK
- `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` / `DEEPSEEK_BASE_URL`：DeepSeek
- 浏览器端 AK（JSAPI GL 交互地图）：优先在根目录 `.env` 设置 `BAIDU_JSAPI_AK`，不要填服务端 AK。本机兼容已有 `frontend/.env.local` 中的 `VITE_BAIDU_JSAPI_AK`，由后端读取用于资源中转，不再打包进前端。配置变更后重启后端；原本机配置可直接沿用。
