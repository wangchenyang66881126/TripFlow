# 固定重庆演示 · 2026-09-30

用户当前以演示为主，要求首页完整分享文案固定、暂不可换。首页 / 侧栏设为只读，隐藏模式切换；点击箭头直接打开预设两日行程。真实模型生成与每日预算保留，可用配置切回。

## 数据与流程

固定数据随源码存于 `backend/app/presets/chongqing/`，读取原重庆示例整理为独立 JSON 与 11 张既有实景缩略图。不依赖原本机数据库，不抓取新笔记、不调用 DeepSeek、不检索 POI / 酒店。

`POST /api/v1/trips/preset` 无需请求字段；返回 `{"trip_id":"cqpreset01","status":"done","preset":true}`（HTTP 200）。首次建档入 SQLite；同一事务内 SQLite 写锁 + 冲突忽略防止并发重复创建。16 个地点和已完成状态持久化；路线文件完整替换后提交，重复进入可修复缺失文件。没有生成后台任务。

原 places / route / app-nav / hotels / photos / share / export 接口继续使用。places 响应新增可选 `preset` 布尔值，demo 的 summary 明确说明预存耗时与评分。照片和酒店直接读取本地预设；导航链接按现有百度规则计算。实时交互地图保留，实际道路以百度导航为准。

修改预设地点或重新规划均返回 HTTP 409 `{"error":{"code":"PRESET_READ_ONLY","message":"这是固定演示行程，暂不支持修改或重新规划。"}}`。结果页不提供调整入口；导出长图标记「预设演示」。

## 演示期间避免误调用

后端 `PRESET_DEMO` 默认 true，原 `POST /api/v1/trips` 在任何模型预算预留前返回 HTTP 409 `DEMO_MODE_ONLY`，提示刷新首页。核验过程中曾观察到旧网页对真实入口的请求，因此增加后端拦截，避免仅靠新首页防止调用。

前端 `VITE_PRESET_DEMO` 默认 true。恢复真实模式需同时将后端设为 false、重启，并用 `VITE_PRESET_DEMO=false npm run build` 重建前端。正式模式的原有模型 / 预算测试继续运行，未删除功能。
